# Ernest Klu Portfolio

Portfolio website for Ernest Klu, architect and sound engineer in Accra, Ghana.

## Stack

- **React 18** + **Vite 5**
- **React Router v6** (file-based page components)
- **CSS Modules** (zero runtime CSS-in-JS, scoped styles per component)
- No UI library; all components are hand-built

## Getting Started

```bash
# Install dependencies
npm install

# Start dev server (http://localhost:5173)
npm run dev

# Production build → dist/
npm run build

# Preview production build locally
npm run preview
```

## Content

Copy and project details live in `src/data/content.js`. Each project has an
`id`, title, category, location, tags and a short description.

## Photos and videos (Cloudinary)

Media is hosted on Cloudinary and resized on the fly, so the site never ships
the multi-megabyte originals. `src/data/media.json` lists every uploaded file
and is generated by the upload script; do not edit it by hand.

1. Put the media in folders, one folder per project, grouped by category:

   ```
   WEBSITE FILES/
     Commercial Projects/
       Akwaaba Rooftop- Madina/   1_1 - Photo.jpg, walkthrough.mp4, ...
     Educational Projects/
       IDL Centre- KNUST/         1.jpg, 2.jpg, ...
     Portrait/                    ernest.jpg   (used on the About page)
   ```

   The folder name becomes the project id (`Akwaaba Rooftop- Madina` ->
   `akwaaba-rooftop-madina`), which must match the `id` in `content.js`.
   Folders without a matching entry still appear, titled from the folder name.
   Files show in file-name order and the first photo is the cover.

2. Create `.env.local` in the project root (it is git-ignored):

   ```
   CLOUDINARY_CLOUD_NAME=your-cloud-name
   CLOUDINARY_API_KEY=...
   CLOUDINARY_API_SECRET=...
   ```

3. Run the upload (Node 18.17+). Add `--dry-run` first to preview:

   ```bash
   npm run media:upload -- "C:\Users\you\Downloads\WEBSITE FILES" --dry-run
   npm run media:upload -- "C:\Users\you\Downloads\WEBSITE FILES"
   ```

   Re-running only uploads new files. Large videos are sent in chunks. The free
   Cloudinary plan rejects single images over 10 MB; the dry run flags those.

4. Commit `src/data/media.json` and deploy.

Projects with no Cloudinary media fall back to their Behance `image`, and
projects with neither are hidden.

## Deployment

Recommended: **Vercel**. `vercel.json` rewrites every route to `index.html` so project pages load on refresh.

```bash
npm i -g vercel
vercel
```

For other hosts (Netlify, Render), ensure the SPA fallback is configured
so React Router handles all routes:
- Netlify: add a `public/_redirects` file: `/* /index.html 200`
- Apache/Nginx: configure a catch-all rewrite to `index.html`
